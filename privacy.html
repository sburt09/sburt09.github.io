Privacy Policy

Shazam Sync — last updated 4 September 2026

Shazam Sync is a personal script used by its owner alone. It runs locally on the owner's own computer and is not offered to other users.

Information the application accesses

With the owner's explicit authorization, the application accesses:

  • Google Drive, read only (https://www.googleapis.com/auth/drive.readonly) — used to list and download image files from a single folder that the owner has designated for Shazam screenshots. The images are read in order to extract song titles and artist names.
  • YouTube (https://www.googleapis.com/auth/youtube) — used to find or create a playlist named "Shazam" on the owner's own account, to read which videos it already contains so that duplicates are not added, and to add matching videos to it.

How the information is used

Data obtained through these services is used only to add songs to the owner's own YouTube playlist. Screenshot images are read in memory while the script runs. The application stores, on the owner's own computer only:

  • an authorization token, so it does not have to ask for sign-in each time;
  • a record of which screenshots and songs have already been processed, so that repeated runs do not add duplicates;
  • a plain-text log of what each run did.

Information sharing

No data is transmitted to the developer, to any server operated by this project, or to any third party. There are no analytics, no advertising, and no tracking. The only network connections the application makes are directly to Google's own APIs in order to perform the actions described above.

Data retention and removal

All files the application creates live in its own folder on the owner's computer and can be deleted at any time. Authorization can be revoked at any time from the owner's Google Account permissions page at myaccount.google.com/permissions, which immediately ends the application's access.

Limited use disclosure

Shazam Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be directed to the project owner via github.com/sburt09.

Shazam Sync is a personal project. It is not affiliated with, endorsed by, or connected to Apple, Shazam, Google, or YouTube.
